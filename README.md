# Сайт «Созвездия» — интерактивная энциклопедия звёздного неба

Интерактивный веб\-сайт, на котором можно изучать звёзды и созвездия: смотреть живую анимацию неба, приближать карту, читать истории и проверять свои знания в викторине.

## Описание проекта

Сайт задуман не как набор статичных картинок, а как живое пространство. При входе пользователь видит анимацию случайных созвездий, которые постоянно меняются и движутся. Дальше он может исследовать интерактивную карту неба, искать созвездия по дате, читать энциклопедию, сохранять понравившиеся статьи в личном кабинете и проходить космическую викторину.

## Цели проекта

- Рассказать, что такое созвездия и звёзды, простым языком.  
- Сделать изучение космоса интересным за счёт интерактивности и анимации.  
- Собрать в одном месте карту неба, энциклопедию и личный кабинет.  
- Дать пользователю возможность проверить знания в игровой форме.

## Основные функции

### 1\. Анимированная главная страница

- При каждом входе на сайт показывается анимация случайного созвездия.  
- Созвездие не статичное: звёзды двигаются, линии плавно прорисовываются.  
- Через некоторое время созвездие меняется на другое.

### 2\. Созвездие по дате

- Пользователь вводит дату (например, дату рождения).  
- Сайт показывает, какое созвездие соответствует этому дню.  
- Есть переход на страницу этого созвездия с подробным описанием.

### 3\. Интерактивная карта звёздного неба

- Карту можно приближать и отдалять, перемещать мышью или пальцем.  
- Звёзды кликабельны: при нажатии открывается карточка звезды.  
- Отображаются линии созвездия.  
- У каждой звезды и созвездия показываются:  
  - название;  
  - расположение на небе;  
  - история и мифология.

### 4\. Энциклопедия

- Раздел «Популярные созвездия».  
- Раздел «Звёзды» (самые яркие и известные).  
- Отдельная страница для каждого объекта: описание, изображение, интересные факты, история.

### 5\. Личный кабинет

- Регистрация и вход.  
- Избранное: можно сохранять понравившиеся созвездия и истории.  
- Статусы «прочитано» и «непрочитано» для статей.  
- Личные заметки или небольшой блог пользователя (простая версия).

### 6\. Поиск

- Поиск по названию созвездия или звезды.  
- Подсказки при вводе.

### 7\. Космическая викторина

- Пользователю показывают схему созвездия без названия.  
- Нужно угадать, что это за созвездие (варианты ответов или ввод текстом).  
- Подсчёт правильных ответов и итоговый результат.

## Роли пользователей и возможности

### 1\. Гость (неавторизованный пользователь)

Посетитель без аккаунта может использовать все основные познавательные и развлекательные функции:

- Просмотр анимированной главной страницы со случайными созвездиями.  
- Подбор созвездия по введённой дате (например, дате рождения).  
- Исследование интерактивной карты неба с масштабированием и кликабельными объектами.  
- Чтение энциклопедии (популярные созвездия, яркие звёзды, мифология).  
- Поиск по сайту с подсказками.  
- Участие в космической викторине для проверки знаний.

### 2\. Зарегистрированный пользователь

Пользователь с созданным аккаунтом получает доступ к персональному функционалу:

- Авторизация и вход в систему через защищённый бэкенд.  
- Ведение раздела «Избранное» (сохранение понравившихся созвездий и историй).  
- Управление статусами чтения («прочитано» / «непрочитано» для статей).  
- Создание личных заметок или заметок в мини-блоге.  
- Сохранение личных результатов и прогресса прохождения викторины.
